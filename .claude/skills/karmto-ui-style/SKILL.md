# สไตล์ UI Karmto

- ธีม: `html[data-theme]` = mermaid / sea / neon / (ไม่มี = macaron); `data-tmode` = full / color; `data-bill`; เปลี่ยนผ่าน `applyTheme_` (~L12191) CSS อยู่ ~L952-1090
- ทุก UI ใหม่ต้องใช้สีจาก CSS variable ของธีม ห้ามฮาร์ดโค้ดสีที่อ่านไม่ออกในบางธีม
- มือถือ 420px ต้องไม่เลื่อนแนวนอน ปุ่มแตะง่าย (≥44px)
- แอนิเมชันแบบ AY: สมจริง/จำลองเหตุการณ์/อินโฟกราฟิกเคลื่อนไหวอธิบายแทนข้อความ — ไม่ใช่ตัวอักษรเด้ง; เคารพ `prefers-reduced-motion`
- สี AY: ชมพูพอดีๆ ตัดดำ/ขาว เริ่ดมีสไตล์ (แนวชมพู-ดำ) ไม่หวานจ๋า

## เช็คลิสต์แคปจอ
macaron, mermaid, sea, neon × tmode full/color ที่ 420px → ดูทีละภาพ: ล้นจอ • ตัวอักษรกลืนพื้น • ปุ่มทับ • แอนิเมชันกระตุก/วนไม่หยุด • ขัดสไตล์ AY

## ฟีดแบ็กหน้าตาที่ AY เคยให้ (ทำแล้ว — ใช้เป็นกฎกับงานใหม่)
- **การ์ดในกลุ่มเดียวกันต้องสีไม่ซ้ำกัน** ใช้ `data-tone` (sky/mint/lemon/pink/lav ...) ไม่ใช่สีเดียวทั้งหน้า — หัวข้อข้อความส่ง ORDER ก็สีไม่ซ้ำ
- **การ์ดในแถวเดียวกันต้องสมดุล** สูง/กว้างเท่ากัน ไม่โหว่ (เคยแก้: P&L, สรุปรายปี, Brand fee)
- **ของที่ควรอยู่บรรทัดเดียวกันต้องอยู่บรรทัดเดียว**: ดรอปดาวน์เดือนอยู่บรรทัดเดียวกับหัวข้อ (เดือนเป็นภาษาอังกฤษ ไม่เขียนคำว่า "เดือน"),
  กล่องไทล์ของเหลือเรียงแถวเดียว, ช่องสินค้า+ผู้ขายบรรทัดเดียวบน iPad/คอม, ปุ่มรองเป็นแท็บเล็กๆ ข้างช่องหมายเหตุ (เช่น ➕ เพิ่มในบิล / + อื่นๆ)
- **กระชับ**: ตารางรายการต้นทุนอ่านง่าย หน่วยรอง (เช่น "/หน่วย") ตัวเล็กกว่าตัวหลัก, ระยะบรรทัดแคบลง, มีแถวรวมท้ายตาราง
- **ปุ่มไอคอนในช่องกรอก** (เช่น 📋 ดึงยอดออเดอร์ในช่องจำนวนซื้อ) — ตัวช่วยแค่ "เติม" ห้ามบันทึกเอง
- **ธีมต้องต่างกันจริง** แต่เป็น design system เดียวกัน: โหมด color = เปลี่ยนแค่สี, full = เปลี่ยนเลย์เอาต์ด้วย; ทุกธีมมีบิลของตัวเอง (ไม่ใช่แค่เปลี่ยนสี)
  เลือกบิลได้ (`data-bill`) — ใบเสร็จ/ป้าย PeriPage ที่ส่งในแชทต้องอ่านง่ายทุกธีม
- **หัวแถบบนตรึง (📌) ต้องตรึงได้ทุกธีมทุกโหมด** — เคยพังเฉพาะ Sea full เพราะทับ `position:relative`; แก้ธีมแล้วเช็ค sticky ทุกครั้ง
- **มือถือห้ามล้นจอ**: กริดบนมือถือใช้ `minmax(0,1fr)` ไม่ใช่ `1fr`, ลูกของ grid/flex ที่มีตาราง/ข้อความยาวใส่ `min-width:0`,
  ตาราง `table.plain td` เป็น nowrap — ชื่อแถวยาวต้องเปิดให้ตัดบรรทัด, ตารางกว้างจริงใส่ใน `.scrollx`
- **อะไรที่ระบบทำแทนต้องเห็นชัด**: เช่น "รันสินค้าตัวถัดไป" ต้องกระพริบกรอบ + toast บอกชื่อสินค้าใหม่ + มีสวิตช์ปิด (เคยมีเคสสลับเงียบแล้วกรอกผิดสินค้า)
- **ฟอร์มที่กรอกค้างห้ามหายเมื่อแตะนอกฟอร์ม** (เก็บร่างไว้ เช่น `dashExpDraft_` ของรายจ่ายด่วน)
- **ป้าย PeriPage นุ่มนวล ไม่แข็ง**; ป้ายรวมทั้งวันหัวเป็น "ORDER" (ไม่เขียน "รวมทั้งวัน"); สาขาที่ตั้งป้ายชื่อเองไม่ขึ้นคำว่า "สาขา"
- **กราฟ**: แท่ง+เส้นคู่กัน เลื่อนซ้ายขวาได้ต่อเนื่อง ไล่สีสวย; แถวในศูนย์บัญชาการ/แจ้งเตือนแตะแล้วพาไปหน้าที่ต้องแก้
- แจ้งเตือน: ป้ายตัวเลขห้ามทับข้อความ, ชื่อเมนูเต็ม "Notifications"
