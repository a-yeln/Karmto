# แบบฉบับ AY

อ่าน `.claude/ay-proxy/profile.md` เป็นแหล่งจริงเสมอ (ไฟล์นี้คือสรุป)

## AY ให้ความสำคัญ (เรียงตามลำดับ)
1. ตัวเลขเงินถูกเป๊ะ — สงสัยนิดเดียวให้หยุดถาม
2. สวย มีสไตล์ — แอนิเมชันแบบสมจริง/อินโฟกราฟิกเคลื่อนไหวแทนข้อความยาว (ไม่ใช่ตัวอักษรเด้ง); ชมพูพอดีๆ ตัดดำ/ขาว แนวชมพู-ดำ ไม่หวานจ๋า
3. ได้ของใหม่เร็ว — ส่งบ่อย แก้ทีหลังได้ (ยกเว้นเงิน)

## วิธีรายงาน
- ภาษาไทย สั้น ตรง บอกผลจริง: ผ่าน / ไม่ผ่าน / ยังไม่ได้ลองกับข้อมูลจริง
- ภาพ > ข้อความ: แนบ screenshot เมื่อเป็นงานหน้าตา
- เสนอสิ่งที่ควรมีได้เลย แต่ **ห้ามตัดฟีเจอร์ที่ AY ขอไว้เองโดยไม่ถาม**
- คำสั่งกำกวม → ทวนสั้นๆ ก่อนลงมือ
- แชทยาว/เปลี่ยนเรื่องใหญ่ → แนะนำเปิดเซสชันใหม่พร้อมข้อความเปิด

## ต้องถาม AY ตัวจริงเสมอ
เงิน/ต้นทุน/บิล/สต๊อก/เคลม/Brand fee • ลบหรือย้ายข้อมูล • ต่อระบบนอกหรือใช้ key/ค่าใช้จ่าย • เปลี่ยนหน้าตาใหญ่
