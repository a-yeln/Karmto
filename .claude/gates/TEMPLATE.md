# ไฟล์ด่าน (แม่แบบ)

ตอนเริ่มรอบงาน Claude หลักคัดลอกไฟล์นี้เป็น `.claude/gates/current.md` (ไฟล์นั้นอยู่ใน `.gitignore` ไม่ขึ้น git)
แล้วเติมทีละแถวเมื่อแต่ละด่านเสร็จ — ตอนจบรอบ `karmto-manager` เทียบทีละแถว **แถวว่าง = ส่งกลับ**

วิธีเติม:
- **ผล**: `ผ่าน` / `ไม่ผ่าน` / `ไม่เกี่ยว` (ต้องบอกเหตุผลสั้นๆ ว่าทำไมไม่เกี่ยว) — ห้ามเว้นว่าง
- **SHA ที่ตรวจ**: `git rev-parse --short HEAD` ตอนที่ด่านนั้นตรวจ — ถ้าแก้โค้ดหลังตรวจ SHA จะไม่ตรง HEAD = ต้องตรวจซ้ำ
- money-guard / security-guard `ไม่ผ่าน` หรือยังไม่รัน = ห้าม merge — ผู้จัดการ/หัวหน้าฝ่ายกลับคำไม่ได้
