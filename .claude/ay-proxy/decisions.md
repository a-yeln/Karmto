# สมุดความเห็นของตัวแทน AY

ตัวแทนเพิ่มแถวทุกครั้งที่ให้ความเห็น — AY ติ๊กช่องสุดท้าย ✅ ตรง / ❌ ไม่ตรง (พิมพ์เหตุผลสั้นๆ ได้)
เมื่อเรื่องประเภทเดียวกันตรงต่อเนื่องหลายครั้ง ค่อยเสนอ AY ให้ปล่อยสิทธิ์ใน `profile.md`

| วันที่ | คำถาม | AY น่าจะเลือก | เหตุผล | AY ✅/❌ |
|---|---|---|---|---|
| 2026-11-12 | Q1 จับคู่ยอดโอน: ยอดไม่ตรงบิลเป๊ะ (ก) ห้ามติ๊กจ่ายจากการ์ด ให้ไปติ๊กที่แถวบิลเอง หรือ (ข) ติ๊กได้หลังยืนยันพร้อมส่วนต่าง | (ก) แบบเข้มในรุ่นแรก | profile ข้อ 1 ตัวเลขเงินถูกเป๊ะมาก่อน; ยอดไม่ตรงควรกรอก "โอนจริง" เองที่แถวบิล (มั่นใจกลาง — เรื่องบิล ต้องถาม AY) | |
| 2026-11-12 | Q2 ช่วง "ใกล้เคียง" ±฿100 สูงสุด 5 ใบ | ตกลง | แค่แสดงให้ดู ไม่ติ๊กจ่ายได้ จึงไม่เสี่ยงเงิน; ปรับตัวเลขทีหลังได้ (มั่นใจกลาง) | |
| 2026-11-12 | Q3 ออฟไลน์/มีคิวค้าง: บล็อกการยืนยันจับคู่ | ตกลง บล็อก | เช็คสดไม่ได้ = เสี่ยงติ๊กซ้ำ/ยอดบิลเปลี่ยน; profile ข้อ 1 (มั่นใจสูง) | |
| 2026-11-12 | Q4 วันที่โอนค่าเริ่มต้น = วันนี้ (แก้ได้) | ตกลง แต่ขอให้วันที่โอนเห็นเด่นในแผงยืนยัน และเตือนเมื่อวันที่โอนก่อนวันที่บิล | AY กระทบยอดย้อนหลังด้วย วันนี้อาจไม่ใช่วันโอนจริง — วันที่ผิดกระทบ cashflow/อายุค้างรับ (มั่นใจกลาง-ต่ำ) | |
| 2026-11-12 | Q5 ผู้สมัครจับคู่ใช้นิยามเดียวกับรายการ "ค้างโอน" (renderOutstanding) | ตกลง | ตัวเลขสองที่ต้องตรงกัน ห้ามมีสูตรยอดบิลชุดที่สอง (มั่นใจสูง) | |
| 2026-11-12 | Q6 สีส่วน "รอตัด" ในถังใช้ var(--accent) ของแต่ละธีม ไม่บังคับชมพู | ตกลง | AY เลือกธีมเอง ถังควรเข้าธีม; ชมพูพอดีๆ ไม่หวานจ๋า (มั่นใจกลาง — ดูจาก screenshot ทุกธีม) | |
| 2026-11-12 | Q7 แตะสั้นที่ปุ่มตัดไม่ตัดอีกแล้ว (toast ให้กดค้าง) และถังนับเฉพาะรอบเบิกที่ยังค้างตัด | ตกลงเรื่องกดค้าง; เห็นต่างเล็กน้อยเรื่องถัง: ต้องมีป้ายบอกชัดว่า "เฉพาะรอบที่ยังค้างตัด" | กดค้างกันนิ้วลั่นกับต้นทุน (ข้อ 1); แต่ "ตัดแล้ว N" ที่ไม่รวมรอบที่ตัดครบแล้วอาจทำให้ AY เข้าใจว่าเป็นยอดรวมทั้งล็อต = ตัวเลขชวนสับสน (มั่นใจกลาง) | |
