# ตัวรอง (วางแผนไว้ ยังไม่สร้าง)

สร้างเมื่อจำเป็น หรือในแอคเคาท์อื่น — คัดลอกโครงไฟล์ agent ที่มีอยู่แล้วแก้หน้าที่

| agent | หน้าที่ | สร้างเมื่อ |
|---|---|---|
| `karmto-debt-manager` | จัดการหนี้โดยเฉพาะ: ตามหนี้สาขา จัดลำดับทวง ร่างข้อความทวงทาง LINE ค้างจ่ายผู้ขาย | งานหนี้เยอะจน accountant ทำไม่ทัน |
| `karmto-researcher-analyst` | วิจัย+วิเคราะห์: ราคาตลาดอาหารทะเล แนวโน้มยอดสั่ง ฤดูกาล เทียบผู้ขาย | AY อยากได้ข้อมูลนอกแอปประกอบการตัดสินใจ |
| `karmto-advisor` | ที่ปรึกษาธุรกิจ ตอบคำถาม/แก้ปัญหา — ส่วนหลักจะไปเป็น AI ในแอป (roadmap ข้อ 5) | หลังทำ AI ที่ปรึกษาในแอป |
| `karmto-line-bot` | ดูแลบอท LINE กลุ่มแบบเงียบ: สลิป→กระทบยอด, รูปออเดอร์→ร่าง, ข้อความ→เตือน AY (ตอนนี้ให้ gs-backend ทำ) | หลังบอท LINE ขึ้นใช้งานจริง |
