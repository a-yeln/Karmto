# โปรแกรมเฝ้ารูป LINE บนคอม (Windows)

ใช้เมื่อบอทของเราเข้ากลุ่ม LINE ไม่ได้ คอมที่ล็อกอิน LINE ของ AY ส่งรูปเข้า Karmto แทน
**สถานะ: ยังไม่ได้ลองบนเครื่อง Windows จริง** (เขียนและตรวจตรรกะฝั่งรับแล้ว แต่ตัวสคริปต์ต้องลองที่คอม AY)

## ขั้น 0 — ตรวจก่อนว่า LINE คอมเซฟรูปเองไหม (ทำครั้งเดียว)
1. ลง LINE สำหรับ Windows แล้วล็อกอิน
2. โหลดโฟลเดอร์ `tools/line-watcher` นี้มาไว้ที่คอม
3. ดับเบิลคลิก `check-line.bat` → ทำตามที่จอบอก (เปิดกลุ่ม รอรูปใหม่เข้า แล้วกด Enter)
4. ส่งข้อความในไฟล์ `karmto-line-check.txt` บนหน้าจอ (Desktop) กลับมาให้ Claude
   - ถ้ามีบรรทัด `JPEG`/`PNG` = LINE เซฟรูปเอง → ทำให้อัตโนมัติเต็มได้ (ชี้โปรแกรมเฝ้าไปที่โฟลเดอร์นั้น)
   - ถ้าไม่มี = LINE ไม่เซฟเอง → ใช้ขั้น 2 แบบกด "บันทึกทั้งหมด" เป็นรอบ

## ขั้น 1 — ตั้งค่า (ทำครั้งเดียว)
1. ทำขั้นตอน ข.4–9 ในหัวไฟล์ `backend/LineBot.gs` ให้เสร็จ แล้วรัน `showKarmtoIntakeUrl` → คัดลอกลิงก์ที่ลงท้าย `/exec?a=intake&t=…`
2. สร้างไฟล์ `watcher-url.txt` ในโฟลเดอร์เดียวกับสคริปต์ วางลิงก์นั้นบรรทัดเดียว แล้วบันทึก (ห้ามส่งไฟล์นี้ให้ใคร)
3. ดับเบิลคลิก `start-watcher.bat` → จะเกิดโฟลเดอร์ `KarmtoLINE` บนหน้าจอ เปิดหน้าต่างดำทิ้งไว้

## ขั้น 2 — ใช้งาน
- เซฟรูปจาก LINE ลงโฟลเดอร์ `KarmtoLINE` (ย้อนหลัง: เปิดกลุ่ม → เมนูรูปภาพ/อัลบั้ม → เลือกทั้งหมด → บันทึกลงโฟลเดอร์นี้)
- ภายใน ~10 วินาทีโปรแกรมส่งรูปให้ระบบ รูปที่ส่งแล้วย้ายไป `KarmtoLINE\sent` รูปที่ระบบไม่รับย้ายไป `KarmtoLINE\failed` ไม่มีการลบ
- รอ 1–2 นาที แล้วเปิดแอป: สลิปขึ้นที่แท็บบิล การ์ด "จับคู่ยอดโอน" · ออเดอร์ขึ้นที่หน้าออเดอร์ แถบ "ร่างออเดอร์จาก LINE"
- แอปโชว์สลิป 3 วันล่าสุด และร่างออเดอร์ 2 วันล่าสุด นับจากวันที่ระบบได้รับรูป

## ข้อจำกัด
- รูปที่ LINE ลบจากเซิร์ฟเวอร์แล้ว (เก่าเกิน) เปิดไม่ได้ จึงเซฟย้อนหลังไม่ได้
- รับเฉพาะ JPG/PNG ไม่เกิน 5 MB ต่อรูป และไม่เกิน 1,500 รูปต่อวัน
- ปิดคอม/ปิดหน้าต่างดำ = หยุดส่ง รูปที่ค้างในโฟลเดอร์จะถูกส่งเมื่อเปิดใหม่
