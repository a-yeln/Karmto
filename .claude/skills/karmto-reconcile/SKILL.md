# กระทบยอดและบัญชี

แหล่งข้อมูล: ไฟล์สำรองจาก `exportAllData` (JSON: `day:YYYY-MM-DD` + คีย์รวม) หรือ `lineInbox:` (สลิปจากบอท LINE ในอนาคต) — **อ่านอย่างเดียว ห้ามเขียนกลับ**

## กระทบยอดโอน
1. ยอดบิลสาขาต่อวัน = ยอดออเดอร์ × ราคา + `billExtra` (ดูวิธีคิดใน `renderBillingList` ~L4612)
2. สถานะจ่าย = `billingPaid` ของวันนั้น
3. จับคู่สลิป: ยอดตรง + วันที่ใกล้ + ชื่อผู้โอน/สาขา → ตรง / ขาด / เกิน / ไม่มีคู่ / สลิปซ้ำ
4. ห้ามเดาคู่ที่ไม่ชัด — ใส่ "ต้องให้ AY ดู"

## P&L และ cashflow
- ใช้สูตรเดียวกับแอป (`computeRangeFinancials`) — สัปดาห์ = จันทร์-อาทิตย์, ปี = ปีปฏิทิน
- Cashflow ใช้ "วันที่จ่ายจริง" ไม่ใช่วันที่ออกบิล
- หนี้: อายุ 0–7 / 8–30 / 30+ วัน ต่อสาขา; หนี้อื่น `loadDebts`

ทุกตัวเลขต้องบอกที่มา (คีย์/วันที่) ข้อมูลไม่พอให้บอกว่าไม่พอ
