# อ่านรูปออเดอร์ (Karmto)

ข้อมูลธุรกิจ (รหัสสาขา ชื่อสินค้า) อยู่ในสกิล `karmto-system-rules` — สินค้า p1–p7 ดู `PRODUCTS` ใน index.html

## รูปที่ AY ส่งจริง
ภาพแคปจอแอปสั่งของของสาขา ตัวพิมพ์ ไม่ใช่ลายมือ:
```
🏪 สาขา 12 สวนหลวง            ← หัว: "สาขา <เลข> <ชื่อ>" หรือ "ธง <ชื่อ>" (= รหัส 00)
Bm9 กุ้งตัดหัว (กก.)     13 กก.  ← "Bm9" คือรหัสหน้าชื่อ ไม่ใช่จำนวน
Bm9 หอยนางรม (กระปุก)   17 กระปุก
```
ชื่อในรูปไม่ตรงชื่อในแอปทุกตัว: กุ้งตัดหัว = กุ้งตัดปาก (p3), หอยเชอรี่ = เนื้อหอยเชอรี่ (p6), หอยนางรม = เนื้อหอยนางรม (p7)

## สูตรที่วัดแล้วได้ผล (5/5 สาขา, 31/31 แถว กับรูปจริง)
1. **เตรียมภาพ** (`prepareOrderImageForOcr_`): ขยาย ~3 เท่า (ด้านยาวไม่เกิน 3000px) + ขาวดำเพิ่มคอนทราสต์ — ตัวไทยเล็กในภาพแคปจออ่านแม่นขึ้นมาก
2. **โมเดลภาษาไทยอย่างเดียว** `createWorker(['tha'])` — ห้ามเพิ่ม `eng`: มันแปลงคำไทยเป็นตัวละติน (ปูจืด → "Uda") และอ่าน "ธง หลักสี่" ผิด
3. **โหมดบล็อกข้อความเดียว** `tessedit_pageseg_mode: '6'`, `preserve_interword_spaces: '1'`
4. **ตัวแยกข้อความ** (`parseOcrText`, `matchProductFromOcrName`, `ocrQtyFromLine_`, `stripOcrSkuPrefix`):
   - ตัดรหัสหน้า "Bm9" ที่ OCR อ่านเพี้ยนเป็น `8ทา9` / `ธิทา9` / `ธ8ทท9` ทิ้งก่อน
   - เอาจำนวนเฉพาะ **เลขที่ติดหน่วย** (กก./กระปุก — OCR อาจอ่านเป็น an / nn / คก.) หรือเลขหลังวงเล็บปิด → ไม่เอาเลข 9 ใน Bm9 มาเป็นจำนวน
   - เทียบชื่อแบบตัดวรรณยุกต์ + รับคำเพี้ยนที่เจอจริง: นาจรม / นบางรม / หอยนา → นางรม; เซอรี่ / ซอรี่ → เชอรี่; คุ้ง/แซ่ → กุ้งแช่;
     หน่วย "กระปุก" มีแค่หอยนางรม ใช้ยืนยันได้
   - แถวที่ไม่มีเลข ดูบรรทัดถัดไปได้ไม่เกิน 2 บรรทัด แต่ **หยุดถ้าบรรทัดถัดไปเป็นสินค้าอีกตัว** (ห้ามยืมเลขของสินค้าอื่น)
   - เจอชื่อแต่หาจำนวนไม่เจอ → ใส่ `unmatched` ให้ AY เห็น ห้ามเดา

## กฎ
- อ่านแล้ว **เติมฟอร์มให้ตรวจ** (รูปเดียว) — หลายรูปบันทึกเฉพาะสาขาที่ยังว่าง ห้ามเขียนทับสาขาที่มีออเดอร์อยู่แล้ว
- ห้ามบอกว่า "แม่นขึ้น" โดยไม่ได้วัด: รันกับรูปจริงก่อน-หลังแก้ แล้วรายงานเป็นตัวเลข (สาขาถูกกี่รูป แถวถูกกี่แถว)
- รูปที่ AY แนบในแชทบางรูปไม่มีไฟล์ในเครื่อง → บอกตรงๆ ว่าวัดได้กี่รูป
- ทุกครั้งที่เจอคำอ่านเพี้ยนใหม่ เพิ่มเคสลง `tests/specs/ocr-order-parse.spec.js` (ใช้ข้อความดิบที่ OCR อ่านได้จริง ไม่ต้องใช้รูป ไม่ต้องต่อเน็ต)

## วัดผลกับรูปจริง
`node ../.claude/skills/karmto-testing/scripts/ocr-real-images.js <รูป...>` (รันจาก `tests/`, ต้องต่อเน็ตโหลดโมเดลภาษา)
ดูข้อความดิบ: ใน `page.evaluate` เรียก `getOcrWorker_()` แล้ว `recognize(await prepareOrderImageForOcr_(url))` พิมพ์ `data.text`

## ถ้าต้องแม่นกว่านี้ (ลายมือ/รูปถ่ายเอียง)
ให้ Claude อ่านรูปผ่าน Apps Script (key ใน Script Properties ไม่อยู่ในโค้ดเว็บ, structured JSON output, ไม่ถึง 1 บาท/รูป) และถอยกลับมาใช้ OCR ฟรีเมื่อพัง —
**ต้องถาม AY เรื่อง key/ค่าใช้จ่ายก่อนเสมอ** (เคยเสนอแล้ว AY ยังไม่สั่งทำ)
