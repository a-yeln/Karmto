# สไตล์ UI Karmto

- ธีม: `html[data-theme]` = mermaid / sea / neon / (ไม่มี = macaron); `data-tmode` = full / color; `data-bill`; เปลี่ยนผ่าน `applyTheme_` (~L12191) CSS อยู่ ~L952-1090
- ทุก UI ใหม่ต้องใช้สีจาก CSS variable ของธีม ห้ามฮาร์ดโค้ดสีที่อ่านไม่ออกในบางธีม
- มือถือ 420px ต้องไม่เลื่อนแนวนอน ปุ่มแตะง่าย (≥44px)
- แอนิเมชันแบบ AY: สมจริง/จำลองเหตุการณ์/อินโฟกราฟิกเคลื่อนไหวอธิบายแทนข้อความ — ไม่ใช่ตัวอักษรเด้ง; เคารพ `prefers-reduced-motion`
- สี AY: ชมพูพอดีๆ ตัดดำ/ขาว เริ่ดมีสไตล์ (แนวชมพู-ดำ) ไม่หวานจ๋า

## เช็คลิสต์แคปจอ
macaron, mermaid, sea, neon × tmode full/color ที่ 420px → ดูทีละภาพ: ล้นจอ • ตัวอักษรกลืนพื้น • ปุ่มทับ • แอนิเมชันกระตุก/วนไม่หยุด • ขัดสไตล์ AY
